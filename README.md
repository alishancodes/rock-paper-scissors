# Rock Paper Scissors

My first JavaScript project from The Odin Project.

I first built the game logic as a console-based JavaScript project. For this version, I reused that logic and added a browser UI with buttons and DOM manipulation.

## This Version

* Choose Rock, Paper, or Scissors using buttons.
* Displays the result and current score.
* First player to reach 5 points wins.
* Buttons are disabled when the game ends.
* Restart button resets the game.

## Issues I Ran Into original version

While building the original version, I had trouble with:

* Understanding how `return` works.
* Understanding variable scope and function parameters.
* Structuring functions properly.
* Generating equally random choices.
* Handling invalid input.
* Keeping game logic separate from output.

I also rewrote and refactored the code several times as I understood these concepts better.

## UI

For this version, I focused on connecting the existing game logic to the browser using:

* DOM manipulation
* Event listeners
* Event delegation
* `event.target`
* `textContent`
* Disabling buttons

## Biggest Takeaway

The biggest challenge was not writing the syntax, but figuring out how to structure the program and then connect that logic to the UI.
